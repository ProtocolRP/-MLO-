FIVEM MAP CONFLICT PREVENTION INSTRUCTIONS

ISSUE:
If you own "Paradise Beach Club" or "Aura Pub" maps, they may conflict with the "Redbrick Coffee Shop" map. To prevent this issue, follow the steps below.


STEPS TO FOLLOW:

1) Overwrite the "vb_occl_01.ymap" file in the following directory: Redbrick Coffee Shop > vanilla

2) From the other two maps ("Paradise Beach Club" or "Aura Pub"), DELETE the "vb_occl_01.ymap" file from the one you are using.

3)RESTART your server.






IMPORTANT NOTES:

The "vb_occl_01.ymap" file SHOULD EXIST IN ONLY ONE LOCATION.

If this file is present in MULTIPLE LOCATIONS, maps may CONFLICT, causing VISUAL ERRORS.

If you experience any issues, CHECK THE SERVER LOGS and VERIFY if any files are MISSING or DUPLICATED.

ENJOY YOUR GAME!
